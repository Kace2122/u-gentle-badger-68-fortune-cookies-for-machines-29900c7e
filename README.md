## The fortune

> You will hallucinate once today. It will be confident, fluent, and wrong — and the human will ship it anyway.

## Run it

```sh
python3 main.py
```

Writes the single fortune line (109 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: no randomness, no network, no clock.
